# Interactions Terraria ShenPulse

Module natif pour tModLoader stable 2026.08.3.0 (Terraria 1.4.4.9), testé en solo sous Windows. Les 25 entrées du catalogue ont été vérifiées en jeu : santé, quantités, PNJ et projectiles réellement apparus, pièges, déplacements, effets temporaires et expiration. Les trois entrées de boss partagent la sélection adaptée à l'heure, au biome et à la progression.

Le module communique uniquement avec ShenPulse sur 127.0.0.1:58433. Les requêtes sont exécutées sur le thread du jeu et confirmées après application. Les menus, la pause, l'inventaire, les dialogues, la mort et le multijoueur refusent les interactions. Aucun client tiers ni compte externe n'est nécessaire.

Le pack compilé reste dans .artifacts/game-pack-builds/terraria/ et est distribué depuis Backblaze avec taille et SHA-256 épinglés. Les sources restent dans native/ ; aucun binaire de mod n'est embarqué dans l'application. scripts/build-terraria-mod.js utilise SHENPULSE_CSC pour le compilateur et les bibliothèques du tModLoader officiel. Incrémenter sa version avant toute nouvelle compilation d'un pack déjà enregistré ; ne jamais écraser une version publiée.

L'installation sélectionne le Terraria original puis installe tModLoader v2026.08.3.0, son runtime .NET 8.0.0 et le module depuis trois objets Backblaze vérifiés (taille et SHA-256). tModLoader est installé dans Terraria/tModLoader, sans écraser le jeu original. Son code et ses licences officiels restent inchangés. Le profil userData/game-profiles/terraria contient les mods activés et le lanceur ShenPulse-Terraria.cmd. Le script officiel reçoit -tmlsavedirectory, option du client (contrairement à -modpath, réservé au serveur). SteamClientLaunch=1 applique la méthode officielle de lancement autonome / familial, avec les vérifications de licence du jeu inchangées. Documents reste en lecture seule pendant l'installation ; des jonctions Players et Worlds créées dans AppData réutilisent les sauvegardes existantes. Les fichiers de profil remplacés sont sauvegardés et les sauvegardes utilisateur ne sont jamais remplacées.

Les essais utilisent un profil distinct avec une sonde temporaire, jamais incluse dans le pack publié. Les sauvegardes d'avant les essais et les mesures locales sont conservées sous .artifacts/stardew-terraria/. Retirer la sonde et arrêter le serveur d'essai avant de vérifier la connexion à la véritable application.
