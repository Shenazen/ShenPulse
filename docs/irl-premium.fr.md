# Accès Premium aux Machines IRL

Machines IRL est réservé à un accès Premium actif. Pro, l’essai Pro, le siège Pro offert par Premium et le Pro offert au directeur d’agence ne donnent pas accès à cette rubrique. Un essai effectivement Premium respecte sa date d’expiration. Les jeux, commandes et matchs conservent leur accès Pro ou Premium.

Le contrat partagé de droits définit le palier par rubrique et sert à la navigation et au processus principal. Le badge IRL affiche PREMIUM ; un clic sans ce droit ouvre les offres. Les listes de types d’actions et les réglages fonctionnels utilisent le même droit.

Les IPC, le service PlugPlus/Shelly et les effets LIVE revalident Premium. Le contrôle est relu après la découverte ou le démarrage Python avant toute nouvelle commande physique. Une action déjà armée conserve son extinction ou sa restauration de fin, même si l’abonnement expire entre-temps. Les comptes, appareils et interactions enregistrés sont conservés ; aucune mutation de facturation ni surclassement automatique.

Les cartes d’offres et leur dialogue, en français et en anglais, placent les Machines IRL dans Premium. Les textes et badges des sources du site public sont alignés.

## Validation

Les tests couvrent les abonnements Pro et Premium, les essais, les accès offerts, les restrictions de visibilité, la navigation et les offres, les IPC et tests directs, les effets différés, les changements de compte/profil et la restauration finale des prises. Les transports matériels sont simulés ; aucune prise réelle n’est actionnée.

Lint et construction native réussis. Les 152 scripts embarqués, le contrat de droits, la garde du processus principal et les styles du badge ont été comparés aux sources. Paquet local : .artifacts/shenpulse-dev-2.1.0-irl-premium/win-unpacked/.

Les quatre fichiers JavaScript du site modifiés passent leur contrôle de syntaxe. La construction globale du site est bloquée par une description publique déjà manquante pour gtav-koth-enhanced dans le catalogue des jeux ; cette tâche ne modifie pas ce catalogue. Aucun site, Store ou installateur public n’est publié pour ce changement local.

Lot final du périmètre modifié : 83 tests réussis, dont le pont Python et la transition Premium vers Pro avant commande différée. Les autres 59 scénarios du lot élargi (navigation, compte, visibilité, architecture) avaient également réussi ; le seul ancien contrat Python identifié dans ce lot a été adapté au palier Premium puis revérifié. Les dix tests des groupes d’actions passent séparément.

Contrôle dans l’application relancée : le menu affiche « Machines IRL · 5 · PREMIUM » et l’infobulle « Réservé à Premium », avec un compte en essai Pro. Le compteur et le nom restent lisibles dans la fenêtre restaurée. Le parcours de clic verrouillé vers les offres est couvert par le test du vrai module de navigation ; aucun achat ni commande de prise physique n’a été exécuté.
