# ShenPulse 2.1.4

## Corrections

- Les combos de cadeaux déclenchent à nouveau toutes les interactions attendues dans les jeux, y compris avec les règles déjà configurées. Au seuil de 1, dix roses produisent dix déclenchements, sans rejouer la série à sa fin.
- Le choix de répéter les combos reste indépendant dans les actions et les sons. Dans les jeux, la répétition est toujours active.
- Correction du bouton de création des packs agences dans l’administration. Les offres restent en préparation, sans prélèvement ni activation automatique d’accès.
