# Crash Bandicoot N. Sane Trilogy

L’intégration ShenPulse remplace l’ancienne fiche de six catégories visuelles par 26 interactions exécutables. L’installateur recherche Steam (application 731490), installe `ShenPulse.CrashBridge.exe` à côté du jeu et conserve une sauvegarde des fichiers remplacés. Le lancement depuis ShenPulse démarre le jeu ou rejoint le processus déjà ouvert.

Le pont 1.0.1 lance le jeu avec `steam://run/731490` et attend une fenêtre stable du bon exécutable avant de s’attacher. La première version ouvrait directement l’EXE et pouvait suivre un processus provisoire remplacé par Steam, puis s’arrêter alors que le vrai jeu restait ouvert. Les essais initiaux avec un niveau déjà ouvert ne couvraient pas ce démarrage. ShenPulse attend maintenant également la connexion TCP effective avant de démarrer sa session de jeu. Un serveur en écoute ou une fenêtre ouverte ne suffit plus à déclarer ce lancement réussi. Les étapes de lancement et de connexion sont journalisées dans `%LOCALAPPDATA%/ShenPulse/game-logs/crash-bandicoot.log`.

Le pont est un programme original .NET Framework x64, sans bibliothèque ni service d’interactions externe. Il se connecte uniquement à `127.0.0.1:58436`, reçoit le protocole JSON terminé par NUL et confirme la commande après écriture et relecture de la mémoire du jeu. Aucun exécutable du jeu n’est modifié sur disque. La version Steam build 2964270 est reconnue par SHA-256 : `170c61d37fb5277dd94b3e41f7a918f227b76bc67aa338f5c97f63ac317b6af3`. Tout autre exécutable est refusé ; les emplacements de code sont également vérifiés en mémoire avant modification.

Les commandes modifient les vies, fruits et caisses ; les autres agissent temporairement sur les sauts, la course, les actions, le sol, la lumière, le champ de vision, les couleurs et la taille du personnage. Les quantités et durées sont configurables. Une variation impossible des compteurs est refusée. Ces compteurs peuvent être sauvegardés par le jeu.

Les commandes sont refusées hors d’un niveau contrôlable. Les effets temporaires se restaurent en pause et reprennent au retour en partie, sans consommer leur durée pendant la pause. Le même effet prolonge sa durée ; une variante incompatible remplace la précédente et récupère son temps restant, dans la limite d’une heure. La déconnexion arrête et restaure les effets. Le transport limite les trames et la file d’attente, expire les requêtes anciennes et déduplique les identifiants d’une connexion.

Compilation et tests natifs : `powershell -NoProfile -File scripts/build-crash-bandicoot-bridge.ps1 -RunTests`. Les contrôles couvrent les 26 commandes, les écritures partielles, les restaurations, les pauses, les prolongations, les variantes, les trames fragmentées et les doublons. L’archive produite doit être recopiée dans le manifeste avec son empreinte et sa taille après chaque reconstruction.

Qualification locale du 20 octobre 2026 : les 26 commandes ont été envoyées via la passerelle TCP ShenPulse au jeu Steam ouvert dans le niveau Dino Might de Crash 3. Les compteurs ont été relus puis ramenés à leurs valeurs initiales. Les modifications temporaires ont été relues puis vérifiées restaurées à expiration ; une déconnexion avec un effet actif a également restauré la mémoire. Le contrôle valide l’exécution et la restauration mémoire dans ce niveau ; il ne constitue pas une validation visuelle de chaque effet dans tous les niveaux des trois jeux.

Qualification du correctif 1.0.1 le même jour : jeu et ancien pont fermés, l’IPC `game:launch` et le runtime du paquet Electron local ont lancé le pont installé, qui a ouvert le jeu via Steam. Le nouveau processus de jeu avait bien Steam pour parent. La connexion a été établie après environ quatre secondes, avant confirmation de la session, et deux requêtes `__status` espacées de sept secondes ont reçu une réponse. Ces requêtes n’ont appliqué aucun effet pendant le chargement. Les 204 contrôles natifs, les six tests de confirmation du lancement et la suite complète de 2 612 tests ont réussi. Le paquet conserve les 737 images ajoutées et les données utilisateur après installation et relance. Cette vérification confirme le nouveau chemin de démarrage, sans reproduire rétrospectivement l’arrêt de l’ancien pont.

Référence fonctionnelle consultée pour les commandes et emplacements : pack public CrashBandicootNSaneTrilogy et son [guide](https://crowdcontrol.live/guides/crashbandicootnsanetrilogy/). Aucun binaire de ce fournisseur n’est redistribué. `native/crash-bandicoot/Tests/LiveSnapshot.cs` permet une relecture indépendante des compteurs et des sites modifiés pour la qualification.
